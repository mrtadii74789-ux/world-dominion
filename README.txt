WORLD DOMINION — Prototype 0.1

This is a private, early browser prototype intended for testing on iPhone Safari.

How to run:
1. Upload index.html to a GitHub repository.
2. In the repository, open Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select main and /(root), then Save.
5. Wait for the Pages URL and open it in Safari.

Requires an internet connection because the map borders and map tiles are loaded from public services.

Current prototype features:
- Clickable real-world country map (country borders from a public GeoJSON source).
- Select a country.
- Experimental treasury, population, income, stability, army and resources.
- Build factory, railway, road, power station and farm.
- Recruit troops.
- Local browser save/reset.
- Simple accelerated game-time simulation.

Important limitations:
- This is not yet a complete game.
- Country values are placeholder test values, not real national statistics.
- AI countries are currently informational placeholders, not active strategic opponents.
- No combat, diplomacy, online multiplayer, server, accounts, or cloud saves yet.
- Do not use this prototype as a real economic or geopolitical simulator.
